NISSA DIMSUM - Website Pemesanan
Cara pakai : buka index.html di browser (klik dua kali).
Edit menu/harga/QRIS : js/config.js
Ganti gambar : taruh di folder images/ lalu sesuaikan nama file di js/config.js
Tampilan : css/style.css
Catatan : daftar pesanan disimpan di browser perangkat yang dipakai (localStorage).
Untuk dipakai banyak HP sekaligus, website perlu di-hosting + database.
